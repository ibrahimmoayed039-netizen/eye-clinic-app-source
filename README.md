# نظام إدارة عيادة النظر — الكود المصدري

## هذا الملف لمن يريد فتح/تعديل الكود مباشرة (مبرمج)
إذا تبي فقط **تستخدم** البرنامج بدون أي تعديل، حمّل ملف `EyeClinicManager-Setup-1.0.0.exe` وثبّته عادي — ما تحتاج هذا الأرشيف إطلاقًا.

## متطلبات التشغيل من الكود
- Node.js (نسخة 18 أو أحدث) مثبّت على جهازك
- اتصال إنترنت (لتحميل الحزم أول مرة فقط)

## خطوات التشغيل
```bash
# 1. تثبيت الحزم (مرة واحدة فقط)
npm install

# 2. تشغيل البرنامج مباشرة (وضع تطوير)
npm start

# 3. بناء ملف exe نهائي لويندوز (يحتاج بيئة ويندوز أو Wine على لينكس)
npm run build:win
```

## هيكل المشروع
```
src/
  main/           عملية Electron الرئيسية (نوافذ، طباعة، IPC)
    main.js       نقطة البداية + كل معالجات IPC
    server.js     خادم Express + كل نقاط API
    printer.js    منطق الطباعة الحرارية (صورة/نصي/اختبار جداول الحروف)
    rawPrinterDriver.js   سائق طباعة خام بديل عبر copy /b
    preload.js    الجسر الآمن بين الواجهة والعملية الرئيسية
  db/
    database.js   تعريف قاعدة بيانات SQLite وكل الجداول + الترحيل التلقائي
  renderer/       واجهة المستخدم (HTML/CSS/JS عادي، بدون أي إطار عمل)
    index.html    الصفحة الرئيسية
    setup.html    شاشة اختيار وضع خادم/عميل عند أول تشغيل
    css/style.css كل التنسيقات
    js/
      api.js              طبقة الاتصال بالـ API
      app.js              منظّم التبويبات وتسجيل الدخول
      print-templates.js  كل قوالب HTML للطباعة
      tabs/               ملف مستقل لكل تبويب بالبرنامج
```

## قاعدة البيانات
SQLite محلية، تُنشأ تلقائيًا أول تشغيل في مجلد بيانات المستخدم بويندوز. كل التعديلات على هيكل الجداول بملف `src/db/database.js` تشمل نظام ترحيل تلقائي (migration) يحافظ على البيانات القديمة عند أي تحديث مستقبلي.

## ملاحظة
هذا الأرشيف **بدون** مجلد `node_modules` (حجمه كبير وقابل لإعادة الإنشاء بـ`npm install`). لو حبيت نسخة جاهزة كاملة بدون أي أوامر، استخدم ملف الـ exe مباشرة.

## البناء التلقائي عبر GitHub Actions
يحتوي المشروع على ملف `.github/workflows/build.yml` يبني نسخة ويندوز (exe) ولينكس (AppImage) تلقائيًا، بدون الحاجة لأي جهاز شخصي.

### طريقة الاستخدام
1. ارفع هذا الكود إلى مستودع (repository) جديد على GitHub.
2. لبناء تجريبي فقط (بدون نشر): افتح تبويب **Actions** بالمستودع → اختر **بناء البرنامج (Build Desktop App)** → **Run workflow**. بعد انتهاء البناء تجد الملفات جاهزة للتحميل تحت **Artifacts** بنفس صفحة التشغيل.
3. لإصدار رسمي منشور تلقائيًا على صفحة **Releases**: أنشئ وسمًا (tag) بصيغة `v` متبوعة برقم الإصدار، مثلًا:
   ```bash
   git tag v1.1.0
   git push origin v1.1.0
   ```
   سيبني GitHub تلقائيًا نسخة ويندوز ولينكس، وينشئ إصدارًا (Release) جديدًا مرفقًا به الملفين مباشرة، جاهزين للتحميل والتوزيع.

لا حاجة لإعداد أي أسرار (secrets) يدويًا — الصلاحية المستخدمة (`GITHUB_TOKEN`) تأتي تلقائيًا من GitHub لكل تشغيل.
